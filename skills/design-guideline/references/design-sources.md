# Карта источников визуального языка

Справочник для скила `design-guideline`: где в проекте лежит дизайн, как его читать и в каком виде фиксировать в `DESIGN.md`. Подгружается на этапе 2.

## Приоритет источников

От самого надёжного к наименее надёжному:

1. **Конфиг дизайн-системы** — объявленные токены. Самый структурированный источник.
2. **Реальные компоненты** — что используется по факту. Решающий источник при расхождении с конфигом.
3. **Глобальные стили и шрифты** — базовые значения, подключение шрифтов.
4. **Скриншоты / прод** — тема, плотность, настроение; то, что из кода не достаётся.

Конфиг говорит «что задумано», компоненты — «что работает». В `DESIGN.md` идёт факт.

## 1. Конфиг дизайн-системы

### Tailwind

- `tailwind.config.{js,ts,mjs}` → `theme` и `theme.extend`: `colors`, `fontFamily`, `fontSize`, `spacing`, `borderRadius`, `boxShadow`, `screens` (breakpoints).
- Tailwind v4: блок `@theme { --color-*: ...; --font-*: ...; }` в CSS-файле — конфиг переехал в CSS.

### CSS-переменные

- `:root { ... }` и `[data-theme="dark"]` / `.dark { ... }` — токены и dark-набор.
- Файлы: `globals.css`, `app.css`, `theme.css`, `tokens.css`, `variables.css`, `index.css`.
- Префиксы переменных: `--color-*`, `--bg-*`, `--text-*`, `--font-*`, `--space-*`, `--radius-*`, `--shadow-*`.

### UI-kit

- **shadcn/ui** — `components.json` (стиль, базовый цвет) + CSS-переменные в `globals.css` (`--background`, `--foreground`, `--primary`, `--muted`, `--border`, `--radius`).
- **MUI** — `createTheme({ palette, typography, spacing, shape })` в theme-файле.
- **Chakra** — `extendTheme({ colors, fonts, fontSizes, space, radii, shadows })`.
- **styled-system / Theme UI** — объект `theme` с теми же ключами.

### Дизайн-токены

- `tokens.json`, `design-tokens.json` — формат Style Dictionary / Figma Tokens: вложенные объекты `color`, `typography`, `spacing` с полями `value`.

## 2. Реальные компоненты

Цель — фактический визуальный язык и состояния.

- Папки: `components/ui/`, `src/components/`, `app/components/`, `lib/components/`.
- По каждому ключевому компоненту (Button, Input, Card, Modal/Dialog, Toast, Badge, Select) — варианты (`variant`, `size`) и состояния (`hover`, `focus`, `active`, `disabled`, `loading`, `error`).
- `Grep` по классам и стилям — какие цвета, отступы, радиусы встречаются чаще всего. Частотность = фактическая система, даже если конфиг объявляет иное.
- Варианты компонентов часто заданы через `cva` / `tailwind-variants` / `clsx` — читать объект вариантов.

## 3. Глобальные стили и шрифты

- Подключение шрифтов: `next/font` (`localFont`, `Google`), `<link href="fonts.googleapis.com">`, `@font-face`, `@import` в CSS.
- Базовая типографика: правила для `body`, `h1`–`h6` в глобальном CSS.
- `font-family` стеки — основной шрифт и fallback-цепочка.

## 4. Скриншоты и прод

Пользователь приложил изображения макетов или ссылку на работающий продукт → прочитать визуально. Извлекать: общую плотность (воздушно / плотно), настроение, акцентные приёмы, стиль компонентов. Числовые значения из изображений не выдумывать — только качественное описание для секции «Тема и атмосфера».

## Чек-лист секций DESIGN.md

Что должно быть собрано до синтеза артефакта:

- **Тема и атмосфера** — 3–4 прилагательных-критерия; плотность; light / dark / both.
- **Цвет** — токены с ролями; семантические (success/warning/danger/info); dark-набор, если тема поддерживается; уровень контраста.
- **Типографика** — шрифты + fallback; шкала (размер / line-height / вес) по уровням.
- **Пространство** — базовая единица spacing + ряд значений; контейнеры; breakpoints.
- **Поверхности** — радиусы; тени / elevation; границы.
- **Компоненты** — ключевые элементы проекта; варианты; полный набор состояний.
- **Можно / нельзя** — правила консистентности под характер продукта.
- **Источник** — перечисление файлов / способа сбора; зафиксированные расхождения.

Данных по секции нет и извлечь неоткуда → не выдумывать значение. Режим extract: оставить пометку и вынести в хвост `PLAN.md`. Режим опрос: взять из обоснованного предложения, отразив это в секции «Источник».

## Формат имён токенов

Имена в `DESIGN.md` совпадают с тем, что в проекте:

- CSS-переменные → `--color-primary`.
- Tailwind / JS-конфиг → `colors.primary`.
- SCSS → `$primary`.

Проект без своего формата (режим опрос, выбран «Пока не решено») → CSS-переменные по умолчанию: `--color-*`, `--font-*`, `--space-*`, `--radius-*`, `--shadow-*`.
