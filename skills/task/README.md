# task

## Назначение

Разбивает план фичи на самодостаточные задачи для последовательной
реализации: создаёт `NN-task.md` и переписывает `plan.md` в компактную карту
(общий контекст + строки задач с чекбоксами и ссылками).

## Место в конвейере

Работает после `planning` или `improve`, когда план слишком велик для одного
прохода. Дальше — `implement`: исполнитель читает карту и ровно одну задачу,
не весь план и не соседние задачи. Если план компактный, задачи не создаются —
скил рекомендует идти в `implement` напрямую.

## Входы

- `./workflow/features/{slug}/plan.md` — авторитет по скоупу
- `./workflow/features/{slug}/feature.md` — авторитет по замыслу
- `./workflow/features/{slug}/design.md`, если есть
- `./workflow/PROJECT.md`, `./workflow/ARCHITECTURE.md`, если есть

## Выходы

- `./workflow/features/{slug}/NN-task.md` — самодостаточные задачи: зачем,
  контекст задачи, шаги, границы файлов, проверяемый done-сигнал
- `./workflow/features/{slug}/plan.md` — компактная карта без деталей задач
- статус фичи `[+]` в `./workflow/PLAN.md` (только если задачи созданы)

## Не делает

- Не пишет код, `tests.md`, `design.md`, документацию.
- Не добавляет работу, которой нет в плане.
- Не выполняет git-операции.

## Когда применять

Пользователь просит разбить план на задачи, или после `planning`/`improve`
план получился большим и многофазным.
